# Architecture du laboratoire

Statut : **référence de la couche de compatibilité** ([ADR-091](../adr/ADR-091-foundation-dossier-authority-and-laboratory-status.md)).

Ces documents décrivent l'architecture de référence V2 du laboratoire (profils système, Platform
Baseline, capabilities, contrats polyglottes, sécurité, exploitation, IA) telle qu'elle gouverne
`factory/`, `starters/`, `capabilities/` et `packages/`.

L'architecture cible d'Enistere Foundation — Foundation Kernel, Control Plane, Engine / Compilation
Runtime, Execution Workers, Extension & Registry Ecosystem, Surfaces & Connectors, AI Gateway / Agent
Runtime — est définie par le document 03 du dossier. Les actifs prouvés ici (normalisation avant
résolution, séparation intent/resolution/plan, digests, modèles immuables, Runtime Contracts, Platform
Baseline, conformance, régénération consciente de l'ownership, goldens, UNSUPPORTED explicite) sont
destinés à être extraits derrière les nouveaux contrats, mission par mission (document 03 §7.8).
